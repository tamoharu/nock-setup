# Macの蓋を閉じてモバイルから開発する

開発先MacのHatiで「設定 → 一般 → 接続先名の電源」を開き、
「電源制御を準備」を押します。旧方式が導入済みなら「電源制御を更新」です。
macOSの管理者承認後に準備が完了します。Mac版アプリにはビルド済みの
補助プログラムを同梱し、利用者のターミナル操作やXcodeは不要です。
準備だけではスリープ防止は有効になりません。
CLIからの導入も `hati power install` で引き続き利用できます（こちらはXcode Command Line Toolsが必要）。

iPhoneの「設定 → 接続先名の電源」、またはデスクトップの
「設定 → 一般 → 接続先名の電源」で
**「電源接続中は蓋を閉じても開発を続ける」**をオンにします。
初期値はオフです。「電源接続中・スリープ防止中」の表示を確認してから蓋を閉じます。
外部ディスプレイは不要です。SSH・Tailscaleなどの既存の接続が必要です。

設定は開発先Macの常駐プログラムに保存され、接続中のiPhoneとデスクトップで
共有します。別のMacには影響しません。各クライアントの終了やウィンドウを
閉じる操作では解除しません。会話を送っていない間も接続待ちのため有効です。
設定をオフにするか電源を外すと解除し、再び電源につなぐと自動で再開します。
Linuxでは変更できません。旧版の常駐プログラムには更新が必要です。

画面の消灯設定は変えません。有効中はAppleメニューからのスリープも抑止します。
手動でスリープさせる前にはこのオプションをオフにしてください。
通気のよい場所で使用してください。既に眠っているMacをこの設定で起こすことは
できません。OS更新・再起動・ログアウト中や熱保護による停止は対象外です。

## 実装と復元

通常のidle sleep assertionだけでは蓋を閉じたときの強制スリープに対応しません。
[Appleの電源管理ソース](https://github.com/apple-oss-distributions/PowerManagement/blob/main/pmset/pmset.m)
にある `disablesleep` は電源種別に関係しないシステム全体の設定です。
`pmset -c disablesleep 1` のみでAC限定とは扱いません。

専用LaunchDaemon `com.deep.hati.power` がIOKitの電源変更通知を監視し、
AC接続を確認でき、保存済みの設定がオンである間だけ
`pmset -a disablesleep 1` を適用します。1秒の監視も併用します。
電源種別が不明なら解除します。ユーザーのNodeやシェルをrootで常駐させず、
root所有のネイティブ実行ファイルだけを起動します。

常駐プログラムはSQLiteの確定済み設定を、所有ユーザーのみ読み書きできる
`requests/preference.json`へ原子的に保存します。補助プログラムはこの設定を
直接監視します。有効期限や常駐PIDへの依存はなく、常駐の終了・クラッシュ・
ハング・更新中もAC接続中のスリープ防止を維持します。オフ操作やバッテリーへの
移行では元の設定を復元します。旧補助プログラムとの移行中だけ従来のleaseも更新します。

補助プログラムは適用前に復元情報を永続化し、解除が確認できるまで残します。
補助プログラムの再起動時は保存設定・AC状態・復元記録を照合し、オンかつACなら
一瞬スリープ可能に戻すことなく継続します。アンインストール時は明示的に復元します。
設定ファイルが失われても、root側の復元記録は残ります。
既に他の設定でSleepDisabledが有効なら、取得せずエラーを表示します。
同じシステム設定を操作する他のスリープ防止ツールとの同時利用は避けてください。

変更は認証済み `GET/POST /v1/power` を使用します。保存は要求ID、サーバーID、
設定revisionで保護し、設定と受理記録を同じSQLiteトランザクションで確定します。
応答が失われた場合は要求の受理記録を照合します。古い要求を再送しても、
別端末で後から変更した設定を上書きしません。

## 削除

オプションをオフにしてからMacで `hati power uninstall` を実行します。
元のスリープ設定の復元を確認してから補助プログラムを削除します。
復元が失敗した場合は復元記録と補助プログラムを保持します。
通常のhatiパッケージ削除前にも、このコマンドを実行してください。

保存場所:

- 希望する設定とrevision: 常駐プログラムのSQLite `machine_power`
- 補助プログラムが読む確定済み設定: `/Library/Application Support/hati-power/requests/preference.json`
- 補助プログラム・復元情報: `/Library/Application Support/hati-power/`
- LaunchDaemon: `/Library/LaunchDaemons/com.deep.hati.power.plist`

## 接続診断

デスクトップの「設定 → 接続先 → 接続診断」、iPhoneの設定にある
「接続診断・切断履歴」で確認できます。認証済み `GET /v1/diagnostics` は
常駐の起動・停止・応答遅延、tmuxの存在・応答不明・サーバー交代、補助プログラムが
受け取ったOSのスリープ・復帰とAC切替を返します。通信断だけではスリープやtmux終了と断定しません。
常駐側はSQLiteに直近80件、補助プログラムは直近40件、各クライアントは接続先ごとの
直近の接続イベントを保持します。会話本文・認証情報・コマンドの出力は記録しません。
履歴は更新後から記録されます。

デスクトップはMacの復帰時にSSH接続を再作成し、iPhoneも前面表示中の通信断後に
3〜20秒間隔で再接続します。ホスト鍵変更・認証・版の不一致は自動再接続の対象外です。
受理結果が不明な送信は既存の要求IDで照合し、別の会話や重複送信を作りません。
